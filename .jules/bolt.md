## 2026-10-26 - Eloquent Subquery Aggregates Nullability & Caching Random Queries
**Learning:** In Eloquent, when checking if a `withAvg('relation', 'column')` aggregate attribute was selected on a model, using `isset($this->attributes['relation_avg_column'])` fails for models with 0 related records because SQL `AVG()` evaluates to `NULL` (and `isset()` returns `false` for `null` values). This triggers an unintended N+1 relationship query fallback. Using `array_key_exists('relation_avg_column', $this->attributes)` correctly detects the attribute presence even when `NULL`. Additionally, featured listings using `inRandomOrder()` on frequently visited routes like homepage should be cached with automatic model event invalidation (`Cache::remember`).
**Action:** Always use `array_key_exists()` when reading subquery aggregate values in Eloquent model accessors, and invalidate cached query results in model `saved`/`deleted` events.
